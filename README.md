Vitalis Clinic — Technical Specification

This repository contains a complete high-level technical and functional specification for a clinical management platform, covering business logic, roles, security, and GDPR compliance, prior to implementation.

The specification is provided as both PDF and interactive HTML documents.

Status

Status: specification complete, implementation not yet started.

Methodology

The specification and its accompanying materials were designed and audited with the assistance of Claude and Claude Code. The process included structured scoping, iterative drafting with AI assistance, and multi-level verification (logical consistency, business-rule checks, and role/security review).

Repository contents

- "VitalisClinic—English.pdf" – high-level technical and functional specification (English PDF)
- "VitalisClinic version_française.pdf" – high-level technical and functional specification (French PDF)
- "Vitalis Clinic — Reference Document (EN_FR).html" – interactive HTML version of the specification (with EN/FR toggle)

Scope

This repository is strictly documentary. It contains the specification and reference materials prepared prior to implementation.

No implementation, deployment, or operational configuration is included in this repository.
